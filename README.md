📌 **Multi-User Collaborative Whiteboard**

A real-time collaborative whiteboard built with HTML5 Canvas, Node.js, Express, and Socket.IO.
Multiple users can draw on the same board simultaneously and see updates instantly.

✨ Features
------------------------
🎨 Drawing Tools – Freehand, lines, rectangles, and circles
🌈 Color Picker – Choose different stroke colors
⚡ Real-Time Sync – All connected users see drawings live via WebSockets
💾 Save Board – Export the current board as an image (PNG)
👥 Multi-User Support – Every user’s input updates the shared board
🚀 Tech Stack

**Frontend:** HTML5, CSS, JavaScript (Canvas API)

**Backend**: Node.js, Express, Socket.IO

Realtime Communication: WebSockets
